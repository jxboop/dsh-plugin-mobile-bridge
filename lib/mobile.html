手机桥已连上

这台手机现在连着你自己电脑上的 DSH。

你可以：

  • 下达任务 —— 在下面输入框说一句话，agent 就开始干。
  • 看实时进度 —— 它的思考过程和每一步工具调用会自己往下滚。
  • 回答提问 / 批准操作 —— 它需要你拍板时会弹出卡片，直接点。
  • 插话 —— 它正在跑的时候，右边按钮是「插话」：现在就能说，你这条会排在这一轮之后接着处理，不用干等。

最底下那一栏一共四页：任务 · 新建 · 🎤录音 · 余额。

  • 左右滑动就能换页，顺序就是这四页：往左滑下一页、往右滑上一页 —— 任务 → 新建 → 🎤录音 → 余额（比如在「新建」上往左滑就是「录音」，再往左才是「余额」）。和点底下那几个键是一回事 ✓。
  • 录音也是一页，划到它就是打开录音面板（不会自动开始录音 —— 麦克风要你自己按）。
  • 录音、生图、背景、权限这些面板上也照样能滑 —— 划走时那个面板自己关掉、直接翻到下一页。（正在录音时会拦一下并告诉你先按「停止」：面板上就是停止键，划走了你够不着它。）
  • 划到头会有提示（"已经是最右边了（余额）"），不会闷着不动 ✓。
  • 正在上下滚动看历史时不会被误判成翻页（竖着滑永远是滚动）；在输入框里左右滑是选文字，也不会翻页。
  • 「新建」/「生图」里写了东西还没用时，划走会先问你一句 —— 免得把写好的内容丢掉。只有说明页和提问卡片会让滑动整个失效（那两处得先处理掉）。
  • 电脑上给你的文档，手机上能直接打开（2.1.0 起）：会话里出现的文稿会多一个「打开 ›」—— Markdown / 文本 / 代码直接渲染，PDF 能翻，Word/Excel/PPT 这类浏览器渲染不了的会给「下载」（用手机上的 WPS/Office 打开）。
  • 会话列表就在顶上那一行（点它打开）：点一行切过去、📌钉到最上面、⭐标成常用、🗑删除。agent 子会话和自检会话默认不摆出来（不占位置），想看在列表底部勾「显示全部会话」。删除要输 PIN；删掉的会话在电脑端「已归档」里还能取消归档找回来。
  • 网页最顶上那一行写着"现在用的是哪个模型"（点开就能换，按会话生效）—— 在电脑上换过模型，这里也会跟着变 ✓。

输入框上面那排按键，从左到右：

  • 图片 —— 拍照或从相册选图发给它（**一次可以多选**：会自动压好、打包成一批发出去，不会让你干等）。大图切片上传时，屏幕上写着"正在上传 … 传到第几片"（不会让你对着一个不动的界面猜）。
  • 录音（最底下那一栏的 🎤）—— 直接在网页里录，不用去系统录音 App 里找文件：录完能先听一遍再发，电脑会自动转成文字给模型。录的是压缩格式（opus），一节课约 10 MB，比系统录音小三分之二。要用 https 地址打开浏览器才给麦克风，录的时候别锁屏、别切走。
  • 视频 —— 选视频也走这个键：传到电脑后自动抽 6 帧给模型看（"视频里讲了什么"能直接答），**视频里的语音还会转成文字**；原片也留在电脑上，要看细节/听声音随时让它处理。
  • 语音 / 录音 —— 语音备忘录、录音也走这个键：电脑会做语音转文字，模型直接"读"到内容（中文识别很准，一分钟约六分钱）。一节课的录音也行（上限 3 小时），只是要先传一会儿 —— 想快就先用「压缩」音质录，或者把文件拷到电脑上让我直接处理。
  • 文件 —— 从手机里挑任意文件（文档、压缩包、代码…）传到电脑上；它拿到的是文件路径，能自己打开读内容。
  • 原图 —— 点亮后按原始画质发，不压缩（大图会慢一些，费流量）。
  • 生图 —— 用一句话让它画一张图或出一段视频（面板上有 🖼 图片 / 🎬 视频 切换）。两者都靠电脑上的生图插件：电脑没装、或者没配好 key，它只会回「没有生图模型」。提示词越具体越准（主体 / 动作 / 风格 / 光线 / 镜头）；视频是分钟级的（免费模型约 1 分钟），出好会直接变成能播的视频。
  • 背景 —— 给这个手机界面换一张图 / 动图（GIF）/ 视频当壁纸。背景是配在电脑上的，连上来的手机看到的都一样。
  • 🔐 —— 这个会话允许它做到哪一步（只读 / 可写工作区 / 完全放开）。改这个要重新输一次 PIN。新建任务时也能先选好：在「新建」那张纸里选一档，建好的那一刻就按它跑（选「跟随默认」就什么都不改）。

连不上时屏幕顶部会弹出一条说明，直接告诉你是电脑睡了、还是地址变了 —— 照着上面写的做就行。彻底连不上时会有一整屏提示（不会只留个黑屏/白屏）：上面写着是哪一类故障、10 秒后自动重试，还有「立即重试」「先看上次的对话（离线能读）」「换个地址」。

  • 🔍 搜一搜 —— 搜这台电脑上的会话内容（不上云），点一条直接跳过去。机器上没开会话检索时，它会如实念出宿主那句话，不会假装"没搜到"。
  • 📅 这周学了什么 —— 最近 7 天有活动的会话列一份；超过 60 条会写明"还有更多"，不让你以为就这些。
  • 📤 导出 / 分享 —— 这份对话导成 Markdown 下载、复制全文，或走系统分享发微信。
  • 📤 分享（顶栏） —— 一键拿到**当前版本的零基础安装文案**（含三步装好 + 仓库地址 ✓），可以复制或走系统分享发给朋友 ✓；里面没有你的密码、密钥、内网地址 ✓。4.1.0 起顶栏就有这个键 ✓。
  • 📋 剪贴板 / 截屏 —— 看电脑剪贴板、把手机上的字发到电脑；📸 一键看电脑屏幕（要现输 PIN，锁屏时它会如实说"截不到"）。3.8.0 起这张纸上还多了两样：「最近放进去的」（你发到电脑剪贴板的文字留最近 20 条，只在这台手机上 —— 点一条只放进输入框，不替你按发送 ✓；⚠️ 从电脑读回来的不进历史：那可能是密码）与 🔤 取字（把这一屏交给电脑上的 agent 认字、存成一份可搜索的笔记 —— 桥自己不认字）。
  • 📊 电脑状态 —— CPU / 内存 / 磁盘 / 网速、哪个进程占着端口、哪个 node 卡住（只有真的能结束的才给「结束」，而且不许杀 DSH 本体）；底部还有「最近批过什么」。3.9.0 起这张纸上还多了两样：💤 我睡了（一键锁屏 + 明早打开页面提醒你听最新一条 ✓ —— 绝不一键关机 ✗）与 🎬 专注模式（一键：网页通知静音 + 「专注中」徽章 + ⏱ 打点把一条带时间的标记发进会话 ✓；⚠️ 录音那一半没做 ✗ —— 网页在后台录音会被 iOS 挂起，做了也是"录到一半没了"）。4.0.0 起还有 🎬 录屏遥控：手机上开始 / 停止电脑录屏 ✓（走同一个 PIN 纸 ✓，最多 10 分钟自动停 ✓ —— 不靠手机计时 ✓，手机断了也照样到点停；默认关，要用先在配置里加 "screenRecord": true ✓）。
  • 📅 定时任务 —— 到点往这个会话发一句话（"每晚 23:00 整理今天的笔记"）；⏰ 工作流可以把"转写 → 出提纲 → 存笔记"这类步骤一行一步串起来跑一遍。
  • 🧩 面板 —— 电脑上放一个目录 + panel.json，手机这里就多一个键（自带的便签、计时器就是例子）。
  • 🩺 一键自检 —— 七条只读检查（桥在听、桌面端在听、开机自启、外网隧道、写权限、ffmpeg…），每条都带"怎么办"。
  • 🛡 安全审计 —— 谁登录过、从哪来、有没有陌生设备；可以一键踢掉其它设备（要输 PIN）。
  • 🔓 解锁 —— 在「📊 电脑状态」那张纸上：把电脑从锁屏/睡眠**唤醒到登录界面** ✓（密码仍要你自己按 ✗ —— 安全桌面不收程序的输入 ✓）；要现输 PIN ✓，3 秒内只发一次 ✓。4.1.0 起这个入口真的通了 ✓。
  • 🔓 只看不发 —— 出门看进度时一键锁住发送，不怕误触（再点一下解锁）。⌨ 是键盘手感：Enter 直接发、↑ 取上一条、长按拖光标。
  • 🔗 只读链接 —— 给别人（家人 / 另一台设备）临时看某一篇会话：默认关，生成要重输 PIN，随时可撤销。4.0.0 起还能勾 「一次性」：谁先打开谁看 ✓，看完就作废 ✓（第二次打开会明确告诉你"别人用过了" ✓ —— 不是含糊的 404 ✓）。

把任何 App 里的东西"分享"进电脑（3.6.0 新增，手机上不用点任何键）： 用 iOS 的快捷指令做一个"分享表"动作 —— 「获取 URL 内容」POST 到桥的一条短链， 请求体写 {"pin":"你的六位 PIN","text":"…"}（有网址就再加 "url"，有图就 "images"）。之后在任何 App 点「分享」→ 选它，内容就进了电脑上最近那个会话 （会带一句【分享到桥】）。⚠️ 默认关：先在这台电脑的 mobile-bridge.json 里加 "shareIntake": true，然后去 🩺 一键自检里抄那条带密钥段的短链； 每次都要带 PIN（它等于替你指挥电脑，和手机上点「发送」同级）。

拍张照就让它认字（一键 OCR）（3.7.0 新增）：同一条快捷指令里再加 "task":"ocr" —— 拍一页书 / 一张名片 / 一块白板，点一下，电脑那边就把它认成文字 并整理成一份 Markdown 笔记（回你文件路径 + 认出来的字）。文字落在会话里， 所以开了「🔍 搜一搜」（电脑上挂了会话检索）就能在手机上搜到它； 没开的话搜一搜会如实说搜不了 —— 文字照样在会话和那份笔记里。另一个预设是 "task":"scan"： 扫二维码 / 条形码 / 书号 —— 电脑把码解出来、再查一下它是什么、把结论回你。

出门在外也要能连 —— 这一步是必需的，不是可选。电脑和手机各装一次 Tailscale、 登录同一个账号，然后在电脑上开一次隧道（tools\tunnel-start.ps1；想让开机自动起来跑一次 tools\autostart.ps1）。验收办法：把手机切到 4G/5G（关掉 WiFi）打开外网地址试一次 —— 🩺 自检里"外网隧道"那一行通不通，就是这一步的答案。隧道断了，电脑上的角标会标红提示。

想让别的程序"听"到（开放接口）：在电脑上的配置文件里写一个 webhookUrl，会话 开始跑 / 跑完、agent 出错、会话有新活动时就会往那里 POST 一条小消息 （带签名、能验真，不带对话内容）。默认关：没写网址就一条都不发。

发出去后 agent 会调 image_generate 出图，图会出现在当前会话里；出图慢时页面会显示它在跑。
发出去后 agent 会调 video_generate 出片。视频是分钟级的（免费模型排队更久，通常 1 分钟左右）；出好之后会以能直接播的视频出现在对话里，长按可以存到相册。
⚠️ 真正出图的是电脑上的 image_generate 工具（一个单独的 DSH 插件）。电脑没装的话，agent 只会回一句"没有这个工具 / 没有生图模型" —— 那是电脑缺插件，不是手机桥坏了，装法见 README。
⚠️ 出片的是同一个插件里的 video_generate（智谱 CogVideoX）。cogvideox-flash 免费（画面带智谱水印）；cogvideox-3 更清晰、可带音频但按量计费。用的是生图那份智谱 key，不用另外配。
⚠️ 国内免费又稳的是智谱 CogView：去 bigmodel.cn 注册拿 key，填进电脑上的 ~/.dsh/image-gen.json（"zhipu": {"key": "…"}），再把 providers 设成 ["zhipu"]。key 要点「复制」拿整串（形如 xxxxxxxx…xxxx.xxxxxxxxxxxxxxxx，中间有一个点，约 49 位）；只复制了点号前面那段，出图时会报「格式不对」。
第一次会先把这句话放进输入框，你看一眼再点发送。
